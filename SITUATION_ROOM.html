claudit▌

Audit what your Claude Code agents actually did — and what it cost.

A Go CLI that reads the .jsonl session logs under ~/.claude/projects/ and reconstructs each session as a trace you can read, filter, and interrogate — every turn, tool call, and sub-agent on a real timeline with automatic anomaly detection — alongside full cost, token, and cache accounting. Runs entirely local. MIT, shipped as go install + prebuilt binaries.

Mode

Steady-state maintenance. Both roadmaps (Phoenix trace viewer, Honeycomb observability) are fully shipped and the 2026-07 principal-engineer audit is fully executed. Current work is keeping claudit correct against upstream reality: pricing vs. Anthropic's published rates, parser vs. Claude Code's JSONL schema. Latest release: v1.8.0 (2026-07-26). → CURRENT.md

04Ruled vs. not yet decided

Standing decisions

  • Session auditor, not spend report — behavior first, cost one dimension. 2026-06-07
  • TDD for all backend + frontend logic; browser verification for UI. No implicit override. (.claude/rules/testing.md)
  • Agents view is serve-only — no static-report parity.
  • Per-view local filters; the dishonest global bar is gone. v1.6.0
  • Spend dedups by message.id; drill-downs must reconcile. v1.7.0
  • Pricing is overlay-style and date-effective. v1.4.3, v1.8.0
  • Date filters resolve in local time. v1.4.0
  • Desktop-only — no mobile/responsive pass.
  • Tracker is GitHub Issues (gh), five-role triage labels. 2026-08-15
Rejected 2026-07-03 — do not re-propose: Sankey diagram · cost treemap/icicle · config file · streaming aggregation · bundler migration · multi-session stacked Gantt.
